Codex Quota 是一个 VS Code 插件。本版简化状态栏菜单，并将位置和语言统一放到 VS Code 设置中。

- 菜单仅保留：刷新额度、查看账号与额度来源、查看诊断日志、打开设置。
- 移除手动环境选择及位置／语言切换命令；查询环境继续由插件安装位置决定。
- 点击“打开设置”即可选择左侧／右侧、跟随 VS Code／中文／English。
- 修改位置或语言立即生效，保留当前额度和查询时间，不重新查询或重载窗口；工作区设置优先于用户设置。
- 原生设置是显示语言的来源，旧菜单保存在插件存储中的语言偏好不再覆盖设置。

下载同一个 VSIX，在本地或对应远程端安装。CLI 与账号、IP、5 小时＋周／仅周额度的查询方式沿用 0.1.9。

本地单元测试、打包入口及已安装 VS Code 宿主测试通过。Windows／Linux CI：[验证结果](https://github.com/jyongli/codex-quota-vscode/actions/runs/38066237727)。实际远程连接的验证限制见 TESTING.md。
