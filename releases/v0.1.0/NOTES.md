Codex Quota 首个版本：在 VS Code 状态栏查看 Codex CLI 当前 ChatGPT 账号的剩余额度。

- 支持本地／远程执行环境选择，宿主切换后重载窗口生效。
- 支持状态栏左／右位置即时切换。
- 存在 5 小时窗口时显示 5 小时与周剩余额度，否则仅显示周额度。
- 通过官方 Codex CLI app-server 的账号和额度接口查询，明确展示账号、执行环境与配置目录来源。
- 支持自动刷新、手动刷新、超时取消；查询失败后清除旧额度。

安装：下载 `codex-quota-vscode-0.1.0.vsix`，在 VS Code 扩展视图选择“从 VSIX 安装”。要求 VS Code 1.95+，在所选环境安装并登录官方 Codex CLI。

发布前验证：30 项测试、9 项打包入口回归、官方 CLI 原生未登录冒烟、真实 VS Code 1.95.3 宿主及 VSIX 安装后测试均通过。

实测范围：真实远程机器、已登录 ChatGPT 账号的线上额度查询和 Windows／macOS 原生启动尚未实测；详见仓库的 `TESTING.md`。
